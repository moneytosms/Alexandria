# Controls & Keyboard Shortcuts Reference

Alexandria is designed to feel fluid with both mouse/trackpad and keyboard. Below is the complete reference across every view.

---

## Global Shortcuts

| Shortcut | Action |
| :--- | :--- |
| `Ctrl + K` / `Cmd + K` | Open global full-text FTS5 search across titles, pages, and notes |
| `Ctrl + ,` / `Cmd + ,` | Open Library Settings & Health dialog |
| `Esc` | Close active overlay/sidebar, or return to the Grand Hall from utility views |

---

## 3D Grand Hall Navigation

| Input | Action |
| :--- | :--- |
| `W` / `↑` | Walk forward in camera look direction |
| `S` / `↓` | Walk backward |
| `A` / `←` | Strafe left |
| `D` / `→` | Strafe right |
| `Shift` (hold while moving) | Walk faster across the nave and mezzanine |
| **Click + Drag** on hall canvas | Look around smoothly (yaw and pitch) |
| **Hover** a book spine | Preview title, author, and reading progress |
| **Click** a book spine | Open Quick Book Preview Card (cover, tags, progress, open in Reader) |
| **Drag** a book spine | Move book directly to another shelf or bay |
| **Walk into Grand Staircase** | Ascend or descend smoothly between the Ground Floor and Upper Mezzanine |
| **Mini-Map Click** | Inspect shelf wing locations and orient yourself in the hall |

> **Navigation Tip:** Focus is automatically released from UI inputs before movement begins—if movement ever feels paused after typing in a search or shelf field, click once on the 3D hall canvas to resume walking immediately.

## Precision PDF Reader

| Shortcut | Action |
| :--- | :--- |
| `←` / `PgUp` | Previous page |
| `→` / `PgDn` | Next page |
| `Home` | Jump to first page |
| `End` | Jump to last page |
| `+` / `=` | Zoom in |
| `-` | Zoom out |
| `H` | Toggle **Highlight** annotation tool |
| `I` | Toggle **Freehand Ink** annotation tool |
| `B` | Toggle bookmark on current page |
| `F` | Toggle fullscreen reading view |
| `Esc` | Close Reader sidebar or exit active annotation tool |

### Reader Pointer Interactions

- **Select Mode:** Highlight and copy crisp PDF text directly from the aligned PDF.js text layer.
- **Highlight Mode (`H`):** Drag over text or click-drag directly on the page; marks anchor to exact normalized page coordinates (`0.0 – 1.0`) so they stay aligned at every zoom level and rotation.
- **Ink Mode (`I`):** Draw freehand underlines, brackets, or notes directly on the page canvas.
- **Eraser Mode:** Click or drag over any existing highlight or ink stroke to delete it without affecting surrounding annotations.
- **Study Mode:** Toggle from the top Reader toolbar to hide non-essential chrome and activate the focused study session timer.

## Floor Map, Index & Librarian Views

| Action | How |
| :--- | :--- |
| **Switch Views** | Top navigation bar (`Room`, `Reader`, `Map`, `Manage`, `Index`) |
| **Bulk Import** | Drag and drop PDFs, Office files, or folders anywhere on the window |
| **Reorder Shelf** | Drag entries in the Shelf Drawer or apply automated sort (Title, Author, Added, Reading State) |
| **Pin to Reading Desk** | Click the pin toggle inside any Quick Preview Card or Book Details drawer |
| **Manage Tags** | Add or remove tags from Book Details or filter volumes by tag in the Index |
